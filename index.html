Parte A Um número basta?

🤔 Reflita antes de responder

1
Se você tivesse apenas x̄ = 220, o que responderia ao gerente? O que falta para ter confiança?
220 ms é apenas a média de uma amostra — é uma estimativa pontual. A probabilidade de a média real (µ) ser exatamente 220 é praticamente zero. Falta quantificar a incerteza: qual é a variabilidade? Quantas observações temos? Com que confiança podemos afirmar que µ < 250?
2
Se outra pessoa coletar outros 25 valores logo em seguida, a média será exatamente 220? Por quê?
Não. A média amostral é uma variável aleatória — cada amostra gera um valor diferente. É por isso que precisamos de um intervalo, não de um ponto. O Teorema do Limite Central nos diz que essas médias se distribuem em torno de µ com desvio padrão σ/√n.
Parte B Intuição de engenharia

💬 Qual frase é mais honesta para reportar?

1
Escolha a frase mais honesta e justifique em 1 frase:
(A) "A média é 220." (B) "A média deve estar por volta de 220, com uma margem." (C) "Não dá para falar nada."
(B) é a mais honesta. (A) apresenta uma estimativa pontual como certeza — tecnicamente imprecisa. (C) é pessimismo desnecessário: os dados existem e permitem inferência. (B) reconhece a incerteza inerente a qualquer estimativa amostral.
2
Em qual situação é mais fácil afirmar "µ < 250"?
(1) n = 25, s = 60   (2) n = 100, s = 60
Situação (2) — n = 100. Com mais observações, o erro padrão cai (σ/√n fica menor), o intervalo de confiança fica mais estreito e mais próximo de 220, tornando mais fácil garantir que o limite superior ainda é < 250.
Parte C Construindo a ideia (sem nomear a fórmula)

🔧 Raciocínio construtivo

1
Como você montaria uma faixa plausível para µ usando 220, 60 e 25? (descreva em palavras)
Partindo da média amostral (220), calculamos o quanto ela pode variar: o "erro" depende da variabilidade (s = 60) dividida pela raiz do tamanho amostral (√25 = 5), dando um erro padrão de 12. Multiplicamos isso por um fator de confiança (zc ou t) e somamos/subtraímos à média — formando o intervalo.
2
O que acontece com a faixa se: i) s aumenta ii) n aumenta iii) mais confiança
(i) s aumenta → faixa mais larga (mais variabilidade = menos precisão).
(ii) n aumenta → faixa mais estreita (mais dados = mais precisão).
(iii) mais confiança → faixa mais larga (para ter mais certeza, o intervalo precisa ser maior).
Parte D Decisão

✅ Respondendo ao gerente

1
Para responder SIM à frase "µ < 250", o que precisa acontecer com o limite superior da sua faixa plausível?
O limite superior do intervalo de confiança precisa ser menor que 250 ms. Se x̄ + E < 250, então podemos afirmar com o nível de confiança escolhido que µ < 250. Verifique: com n=25, s=60, x̄=220 e 95% de confiança, E ≈ t₂₄,₀.₀₂₅ · (60/√25) = 2,064 · 12 ≈ 24,8 ms → IC: [195,2 ; 244,8] — limite superior abaixo de 250! ✅

Módulo 01

Por que estatística inferencial?

Com base em amostras, tiramos conclusões sobre a população inteira — com um grau de confiança mensurável.

📊

Estatística Descritiva

Já aprendemos a coletar, organizar e descrever dados; analisamos distribuições discretas e contínuas.

🔍

Inferência Estatística

Estudar uma amostra de um universo de discurso e tirar conclusões para toda a população, com grau de confiança associado.

🗳️

Exemplo Prático

As pesquisas eleitorais: feitas com uma pequena amostra, estimam com boa aproximação o resultado de toda a população — com margem de erro.

💡
Objetivo: usar amostras para estimar parâmetros populacionais desconhecidos — como a média µ e o desvio padrão σ — de forma que a estimativa seja a mais precisa possível.
Módulo 02

Estimativa Pontual vs. Intervalar

Uma estimativa pontual fornece um único valor; uma estimativa intervalar fornece um intervalo com probabilidade de conter o parâmetro real.

📍 Estimativa Pontual

  • ✦ Valor único estimado para µ ou σ²
  • ✦ Fácil de calcular: x̄ = Σxᵢ / n
  • ✦ Probabilidade zero de ser exata
  • ✦ Ex: x̄ = 12,4 (logo, estimativa de µ = 12,4)

📏 Estimativa Intervalar

  • ✦ Intervalo para o parâmetro desconhecido
  • ✦ Inclui margem de erro E
  • ✦ Probabilidade c de conter µ
  • ✦ Ex: 10,3 < µ < 14,5

Módulo 03

O Intervalo de Confiança

O IC associa um nível de probabilidade c (confiança) à estimativa intervalar, usando a curva normal padrão.

A área central c é o nível de confiança; as caudas têm área ½(1−c) cada.

Valores Críticos Comuns

Nível de Confiança (c) Área em cada cauda −zc +zc
90% 0,05 −1,645 1,645
95% 0,025 −1,96 1,96
99% 0,005 −2,576 2,576
📖
Teorema do Limite Central: quando n ≥ 30, a distribuição das médias amostrais aproxima-se de uma distribuição normal, independentemente da distribuição original — o que nos permite usar a tabela Z.
Módulo 04 · Ferramenta Essencial

Como usar a Tabela Z no IC

No IC, a lógica de uso da tabela Z é o inverso do que você fazia antes. Entender essa virada é fundamental.

⬅️ Antes: z → probabilidade

  • ✦ Você tem um valor z
  • ✦ Procura na tabela a área acumulada à esquerda: Φ(z) = P(Z ≤ z)
  • ✦ Obtém a probabilidade
  • ✦ z = 1,33 → Φ(1,33) ≈ 0,9082
  • Interpretação: 90,82% da área fica à esquerda de 1,33

➡️ Agora: probabilidade → z

  • ✦ Você tem a probabilidade-alvo (a confiança)
  • ✦ Procura na tabela o z que produz aquela área
  • ✦ Obtém o valor crítico zc
  • ✦ 0,975 na tabela → z = 1,96
  • É o inverso: você tem Φ(z) e quer achar z
Resumo em uma frase Antes: "Tenho z → acho Φ(z)."   Agora: "Tenho Φ(z) → acho z."

Por que procurar 0,975 (e não 0,025)?

A tabela Z dá a área acumulada à esquerda. A cauda direita (α/2) fica no lado oposto — então você precisa converter.

Para IC de 95%: a área acumulada até zc é 0,975 — você procura 0,975 na tabela Z.

Casos mais comuns

Confiança (c) α = 1 − c α/2 (cauda) Alvo na tabela
(1 − α/2)		 zc encontrado
90% 0,10 0,05 0,9500 1,645
95% 0,05 0,025 0,9750 1,96
99% 0,01 0,005 0,9950 2,576
⚠️
Nos slides, "procurar 0,05 na tabela" só faz sentido para IC de 90% — quando α/2 = 0,05 e o alvo acumulado é 1 − 0,05 = 0,95. Para 95%, você procura 0,975. Para 99%, procura 0,995.

Passo a passo: como achar zc na tabela

1

Defina o nível de confiança

Ex.: 95% → c = 0,95

2

Calcule α

α = 1 − c = 1 − 0,95 = 0,05

3

Divida por 2 (IC bilateral)

α/2 = 0,05 / 2 = 0,025

4

Converta para área acumulada à esquerda

alvo = 1 − α/2 = 1 − 0,025 = 0,975

5

Procure 0,975 no corpo da tabela

Encontre a célula mais próxima de 0,9750.

6

Leia linha + coluna → zc

Linha dá as duas primeiras casas (ex.: 1,9), coluna dá a terceira (ex.: 0,06) → zc = 1,96

⚠️ Atenção

E se a tabela mostrar a área entre 0 e z?

Algumas tabelas não dão Φ(z) = P(Z ≤ z), mas sim A(z) = P(0 ≤ Z ≤ z) — a área apenas entre 0 e z. Nesses casos, o cálculo muda:

Tabela Φ(z) — área acumulada

Para IC 95% → procure 0,9750 na tabela

Tabela A(z) — área entre 0 e z

Para IC 95% → procure 0,4750 na tabela
(0,5 − 0,025 = 0,475)

💡
Por isso é importante saber qual versão da tabela você está usando antes de fazer a leitura. O resultado final (zc = 1,96) é o mesmo — só o valor que você procura na tabela muda.

Módulo 05

IC com Variância Populacional Conhecida

Quando σ é conhecido, usamos a distribuição Z para construir o intervalo de confiança.

Margem de Erro
E = zc · (σ / √n)
Intervalo de Confiança para µ
x̄ − E < µ < x̄ + E
1

Calcule a média amostral x̄

x̄ = Σxᵢ / n

2

Identifique o desvio padrão populacional σ

Dado pelo enunciado (variância conhecida).

3

Encontre o valor crítico zc

Na tabela da normal padrão, localize zc correspondente ao nível de confiança.

4

Calcule a margem de erro E

E = zc · σ / √n

5

Forme o intervalo

Extremo esq. = x̄ − E  |  Extremo dir. = x̄ + E

Módulo 06

IC com Variância Desconhecida — Amostras Grandes

Quando σ é desconhecido e n ≥ 30, substituímos σ pelo desvio padrão amostral s e continuamos usando a distribuição Z.

Variância Amostral (estimador de σ²)
s² = (1/(n−1)) · Σ(xᵢ − x̄)²
Margem de Erro com s

Módulo 07

Distribuição t-Student — Amostras Pequenas

Quando n < 30 e σ é desconhecido, não podemos usar a distribuição Normal — utilizamos a distribuição t de Student.

Quando n → ∞, t → N(0,1). Para amostras pequenas, as caudas são mais pesadas.

φ

Graus de Liberdade

O parâmetro φ identifica a curva t a usar: φ = n − 1, onde n é o tamanho da amostra.

α

Nível de Significância

α representa a área na cauda direita. Para IC bilateral de 95%, α = 0,025 em cada cauda.

E

Margem de Erro

Substituímos zc pelo valor t: E = tφ,α · (s / √n)
